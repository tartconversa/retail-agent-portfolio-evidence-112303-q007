# 资料契约

下列记录为确定性生成的本地合成资料，不含真实主体信息。不同文件通过标识字段关联，版本、生效时间、缺失状态和回执字段保留原始业务含义。

| 文件 | 字段 | 记录数 |
| --- | --- | ---: |
| `candidate_scenarios.csv` | `scenario_id`, `department`, `process`, `monthly_volume`, `baseline_hours`, `error_rate`, `target_kpi`, `owner_state` | 36 |
| `dependencies.csv` | `scenario_id`, `dependency`, `capacity_units`, `shared_group`, `readiness_state`, `version` | 72 |
| `governance_reviews.csv` | `review_id`, `scenario_id`, `data_scope`, `purpose`, `risk_level`, `decision`, `reviewed_at` | 48 |
| `funding_stages.csv` | `stage_id`, `scenario_id`, `amount`, `release_condition`, `committee_decision`, `released_amount`, `result_state` | 54 |
| `pilot_results.csv` | `result_id`, `scenario_id`, `period`, `observed_volume`, `observed_hours`, `outcome_value`, `measurement_state`, `source_version` | 60 |

数据缺失、待审、争议和未回执均表示状态未知或处理中，不能解释成零值或成功。记录中的模拟日期用于复现跨期关系，不表示真实业务发生。
